# Keyboard shortcuts

Every menu command with a shortcut, and the keys that work in the editor, Quick Open and the sidebar. They work on the
Mac and on an iPad with a hardware keyboard (hold ⌘ to see them). On Linux and Windows, the shortcuts written with ⌘
use Ctrl.

## File

| Shortcut | Does |
|---|---|
| ⌘N | **New Note**, in the place you're looking at |
| ⇧⌘N | **New Folder** |
| ⌥⌘N | **New Window** |
| ⌘K | **Quick Open…** |
| ⌘S | **Save** |

**File ▸ Encrypt New Notes** has no shortcut.

## View

| Shortcut | Does |
|---|---|
| ⇧⌘E | **Edit Note** / **Read Note** |
| ⌘R | **Reload** |

## Format

These work while a note is open in **Edit**.

| Shortcut | Does |
|---|---|
| ⌥⌘1 | **Title** |
| ⌥⌘2 | **Heading** |
| ⌥⌘3 | **Subheading** |
| ⌘B | **Bold** |
| ⌘I | **Italic** |
| ⇧⌘X | **Strikethrough** |
| ⌘E | **Code** |
| ⇧⌘K | **Add Link** |
| ⇧⌘L | **Checklist** |
| ⇧⌘7 | **Bulleted List** |
| ⇧⌘9 | **Numbered List** |
| ⌘' | **Block Quote** |
| ⌥⌘C | **Code Block** |
| ⌥⌘T | **Table** |
| ⌘- | **Toggle List** |
| ⌘= | **Toggle Checkbox** |
| ⌘+ (⇧⌘=) | **Toggle Checked Checkbox** |
| ⌘` | **Toggle Code** |
| ⌘. | **Toggle Note** (a quote) |
| ⌘1 | **Toggle Numbered List** |

## Window and app

| Shortcut | Does |
|---|---|
| ⇧⌘1 | **Window ▸ Welcome to Markdown** |
| ⌘[ | **Back** (the toolbar's ‹ button) |
| ⌘] | **Forward** (the toolbar's › button) |
| ⌃⌘1 … ⌃⌘9 | Switch to vault account 1 to 9 (with two or more accounts) |
| ⌘, | **Markdown ▸ Settings…** (Mac) |

## Editing

| Shortcut | Does |
|---|---|
| ⌘Z | Undo |
| ⇧⌘Z | Redo |
| Return | Continue a list or quote; on an empty item, end it (Mac, iPhone and iPad) |

## Quick Open

| Shortcut | Does |
|---|---|
| ↑ ↓ | Move through the results |
| Return | Open the result or run the command |
| Esc | Close Quick Open |

## Sidebar

| Shortcut | Does |
|---|---|
| ← → | Close or open the selected folder |
| ⌘-click, ⇧-click, ⇧↑ ⇧↓ | Select several notes (Mac) |
| Delete | Move the selected notes to the Trash (Mac and Windows) |
