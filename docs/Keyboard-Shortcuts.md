# Keyboard shortcuts

These work on the Mac. On an iPad with a hardware keyboard, the same shortcuts work: hold ⌘ to see them.

## Notes and windows

| Shortcut | Does |
|---|---|
| ⌘K | **Quick Open…** |
| ⇧⌘N | **New Folder** |
| ⌘S | **Save** |
| ⌘R | **Reload** |
| ⇧⌘E | **Edit Note** / **Read Note** |
| ⌘[ | **Back** |
| ⌘] | **Forward** |
| ⇧⌘1 | **Welcome to Markdown** |
| ⌃⌘1 … ⌃⌘9 | Switch to vault account 1 to 9 (with two or more accounts) |
| Delete | Move the selected notes to the Trash (Mac) |
| ⌘, | **Settings…** (Mac) |

**File ▸ Encrypt New Notes** has no shortcut.

## Format

| Shortcut | Does |
|---|---|
| ⌥⌘1 | **Title** |
| ⌥⌘2 | **Heading** |
| ⌥⌘3 | **Subheading** |
| ⌘B | **Bold** |
| ⌘I | **Italic** |
| ⇧⌘X | **Strikethrough** |
| ⌘E | **Code** |
| ⇧⌘K | **Add Link** |
| ⇧⌘L | **Checklist** |
| ⇧⌘7 | **Bulleted List** |
| ⇧⌘9 | **Numbered List** |
| ⌘' | **Block Quote** |
| ⌥⌘C | **Code Block** |
| ⌥⌘T | **Table** |
| ⌘- | **Toggle List** |
| ⌘= | **Toggle Checkbox** |
| ⇧⌘= | **Toggle Checked Checkbox** |
| ⌘` | **Toggle Code** |
| ⌘. | **Toggle Note** (a quote) |
| ⌘1 | **Toggle Numbered List** |

The **Format** shortcuts work while a note is open in **Edit**.

## Editing

| Shortcut | Does |
|---|---|
| ⌘Z | Undo |
| ⇧⌘Z | Redo |
| Return | Continue a list or quote; on an empty item, end it |

## Quick Open

| Shortcut | Does |
|---|---|
| ↑ ↓ | Move through the results |
| Return | Open the result or run the command |
| Esc | Close Quick Open |

## Sidebar

| Shortcut | Does |
|---|---|
| ← → | Close or open the selected folder |
| ⌘-click, ⇧-click | Select several notes (Mac) |
